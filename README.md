## 🛠️ Troubleshooting

### "I Can't Connect to the Program"
- Make sure Ollama is running (check your taskbar)
- Make sure you typed `http://localhost:8000` correctly
- Try restarting your computer and starting over

### "The AI Doesn't Respond"
- Check that you downloaded all four models using the commands above
- Make sure you have enough free RAM (close other programs)
- Wait a moment - the first response can take longer as the model loads

### "The Window Closes Immediately"
- Make sure you extracted the files completely
- Try running the `run.bat` file as administrator (right-click → "Run as administrator")
